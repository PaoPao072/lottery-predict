# 🔮 双色球专业预测系统

> Multi-Factor Composite Scoring Model · PhD Grade Statistical Analysis

## ⚠️ 重要声明

**彩票开奖是独立随机事件。** 任何统计模型均无法准确预测随机事件的结果。本系统仅供学术研究和娱乐参考，所有推荐不构成投注建议。请理性购彩，量力而行，切勿沉迷赌博。

## 快速开始

双击 `index.html` 即可在浏览器中打开使用。无需安装任何软件。

## 核心功能

### 🎯 本期推荐（首页）
- **上期开奖号码** — 最新一期真实开奖结果展示
- **本期推荐** — 基于7因子加权综合评分模型自动生成推荐号码
- **置信度评估** — 综合评分一致性分析
- **评分明细表** — 各因子评分逐项展示
- **模型决策逻辑** — 推荐理由和组合特征分析

### ❌ 杀号分析
- **红球杀号**：推荐排除评分最低的 10 个号码
- **蓝球杀号**：推荐排除评分最低的 5 个号码
- 每个杀号附带详细扣分原因和因子分析

### 💎 定胆与大底
- **独胆**：综合评分最高的单一红球号码（最高置信度）
- **红球定胆**：评分前 3 的红球（3胆）
- **蓝球定胆**：评分前 2 的蓝球（2胆）
- **红球大底**：评分前 18 的红球（约55%号码池，覆盖约85%历史中奖号码）

### 📊 频率冷热
- 红球频率柱状图（1-33）
- 蓝球频率柱状图（1-16）
- **红球冷热温分类** — 热号/温号/冷号清晰展示
- **蓝球冷热温分类** — 独立蓝球冷热分析

### 📈 走势图
- 红球/蓝球出现矩阵（最新→最早排列）
- 号码遗漏标注行
- 支持30/50/100期切换

### 🔍 遗漏分析
- 当前/平均/最大遗漏统计
- 回补指数计算
- 遗漏对比图表

### 📐 综合指标
- 奇偶比、和值走势、三区分布、AC值分布
- 统计卡片概览

### 🎲 智能选号
基于评分权重的加权随机生成，优于纯随机。

## 预测方法论

### 多因子综合评分模型（7因子）

| 因子 | 权重 | 理论基础 | 说明 |
|------|------|----------|------|
| 遗漏回归 | 25% | Poisson过程·均值回归 | 高遗漏号码获得更高评分 |
| 频率稳定 | 20% | 大数定律·Z-score | 评估实际频率与理论期望的偏离 |
| 冷热趋势 | 15% | EWMA(λ=0.3) | 短期热度变化趋势检测 |
| 区间平衡 | 15% | 供需均衡·轮动规律 | 三区间(1-11/12-22/23-33)平衡 |
| 关联规则 | 10% | Apriori·共现概率 | 与近期热门号码的关联度 |
| 模式匹配 | 10% | 结构相似度 | 历史中奖模式匹配 |
| 随机扰动 | 5% | 正则化·抗过拟合 | 可控随机噪声 |

### 置信度说明
- **≥75%**：高置信度 — 各因子评分一致性好
- **60-74%**：中等置信度 — 多数因子指向一致
- **<60%**：参考级别 — 各因子分歧较大

**注意**：置信度仅表示评分的一致性和稳定性，不表示中奖概率。
