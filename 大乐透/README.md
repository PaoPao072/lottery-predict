## 大乐透简介

大乐透（超级大乐透）是中国体育彩票的主要玩法，每周一、三、六21:25开奖。

- **前区（1-35）**：选择 5 个号码
- **后区（1-12）**：选择 2 个号码
- **一等奖**：5+2 全中

## 核心功能

### 🎯 本期推荐（首页）
- **上期开奖号码** — 最新一期真实开奖结果 + 和值/跨度分析
- **本期推荐** — 基于量子启发概率融合模型的单式推荐（5+2）
- **复式推荐** — 6+3复式（前区6码 + 后区3码，18注36元）
- **置信度评估** — 前区/后区综合置信度
- **评分明细表** — 7因子评分逐项展示

### ❌ 杀号分析
- **前区杀号**：排除评分最低的 10 个号码
- **后区杀号**：排除评分最低的 5 个号码
- 每个杀号附带详细扣分原因和因子分析

### 💎 定胆与大底
- **独胆**：前区综合评分最高的单一号码
- **前区定胆**：评分前 3 的前区号码（3胆）
- **后区定胆**：评分前 2 的后区号码（2胆）
- **前区大底**：评分前 18 的前区号码

### 📊 频率冷热
- 前区频率柱状图（1-35）
- 后区频率柱状图（1-12）
- 前区冷热温分类（热号≥3 / 温号 / 冷号≤1）
- 后区冷热温分类（热号≥5 / 温号 / 冷号≤2）

### 📈 走势图
- 前区/后区出现矩阵（最新→最早排列）
- 号码遗漏标注行
- 支持30/50/100期切换

### 🔍 遗漏分析
- 前区/后区独立遗漏统计
- 当前/平均/最大遗漏 + 上次出现期号

### 📐 综合指标
- 前区和值、跨度、奇偶比、五区分布
- 近20期详细数据明细

### 🎲 智能选号
基于评分权重的加权随机生成，支持5/10/20组。

### ✏️ 自选号
- 前区 1-35 自选 + 后区 1-12 自选
- 实时计算注数和金额（C(m,5) × C(n,2) × 2元）

### 📋 预测记录
- 单式和复式推荐自动保存
- 开奖后自动比对，显示命中数
- 双统计卡：单式/复式命中率

### 🧪 回测验证
模拟模型在历史数据上的表现，可视化命中情况。
